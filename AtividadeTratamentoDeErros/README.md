# Atividade 2 - Tratamento de Erros em Java

## Como abrir no IntelliJ

1. File → Open
2. Selecione a pasta Atividade2_TratamentoDeErros
3. Trust Project

## Estrutura

- src/
  - Exercicio01.java até Exercicio14.java
  - exceptions/ (classes de exception personalizadas)

- FormatoInvalidoException
- ListaVaziaException
